# EPUB

MiraSpeak module. Opens an EPUB and reads it aloud from any sentence, following along on the page.

Needs MiraSpeak with module API 1. It reads the book with the Python standard library. Book scripts and remote resources never run.

## Install

In MiraSpeak, open **Integrations → Modules → Install from GitHub** and paste:

https://github.com/miramocha/MiraSpeak-epub

Leave the ref blank for the default branch, or enter `v0.1.0`.

It asks for **speak** only. A Python module still runs inside MiraSpeak with the same access as the app.
